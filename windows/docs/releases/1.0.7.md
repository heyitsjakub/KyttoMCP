# Kytto 1.0.7 for Windows

This release follows the macOS 1.0.7 source. MCP Doctor can now pin a package
that a server launches without an exact version, clients with a documented tool
cap show how close they are to it, and "Check latest release" works for
packages with a long release history.

## Highlights

- **Unpinned package versions.** Doctor reports `unpinned-package` for servers
  launched through `npx`, `npm exec`, `pnpm dlx`, `yarn dlx`, `bunx`, `uvx`,
  `uv tool run` or `pipx run` without an exact version. The parser also
  recognises the Windows spellings: `npx.cmd`, `.exe`/`.bat`/`.ps1` runners,
  full or quoted paths and `cmd /d /s /c <runner> …`. After an explicit
  **Check latest release**, the `pinPackageVersion` fix previews the argument
  before and after in every editable client and splices that one `args` string
  through `ConfigWriter`, including copies Kytto holds for switched-off
  servers. A lookup older than 24 hours must be repeated before pinning,
  because this port keeps lookups in `metadata.json` across launches.
- **Tool-count limit.** `ClientToolLimit` on the client descriptor, with VS Code
  at 128 tools per request. `toolBudget` on the client DTO counts the tools of
  servers switched on in that client, subtracts Gateway-masked tools and lists
  servers not yet measured. The client screen shows a tools tile and a "Tool
  limit" section; the matrix header shows `N / 128` when near or over.

## Fixed

- **"Check latest release" and long release histories.** The lookup fetched an
  npm package's full metadata and refused anything over 64 KB, which many MCP
  packages exceed. It now requests `/<package>/latest`; the response cap is
  4 MB because PyPI's JSON still lists every release.
- `TomlRoundTripTests.SwitchingOffWritesOneLineAndMovesNothing` failed on a
  CRLF checkout (`core.autocrlf`). The assertion now ignores the trailing `\r`;
  the byte-for-byte round-trip checks are unchanged.

## Compatibility

`doctor.applyFix` accepts the `pinPackageVersion` action with a `version` and
now answers with `UnifyResultDTO`, so `parkedUpdated` and `parkedFailures`
reach the page. The client DTO gains `toolBudget`. See [`../ipc.md`](../ipc.md).
