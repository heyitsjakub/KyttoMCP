# Kytto 1.0.5 for Windows

Kytto 1.0.5 brings the Windows shell to parity with the current macOS
configuration-management features.

## Highlights

- Restart notices now track net configuration changes, support per-client
  acknowledgement or dismissal, and use the exact singular/plural wording.
- Health-check timeouts report a usable whole-second duration, including short
  positive budgets.
- Claude Code projects from `.claude.json` appear as deterministic, opaque,
  read-only workspace clients.
- A bounded local MCP library scanner and strict JSON agent import flow provide
  preview-first discovery without executing code, contacting registries or
  exposing secrets.
- Server provenance is surfaced as native metadata, with explicit, cached
  first-party latest-version checks and maintenance health states.
- The updater now verifies the first-party manifest and package hash, downloads
  into private app data with progress/cancellation, and requires an explicit
  install action.
- Skills inventory is read-only, bounded and metadata-only across known global
  and workspace roots.

## Compatibility and safety

Existing client configuration formats remain compatible. Imports use the normal
backup, digest-guarded and atomic authoring pipeline, and read-only project,
library and skill sources never become write destinations. Environment values
remain native-only; only safe key names and presence metadata cross IPC.
