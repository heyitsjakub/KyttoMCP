# Kytto 1.0.4.1 for Windows

Kytto 1.0.4.1 is the Windows updater bootstrap release. It keeps the existing
configuration and installation behavior, and adds the first-party update check
and download entry point so future releases can be surfaced from inside Kytto.

## Highlights

- Checks Kytto's first-party Windows update manifest without sending
  configuration, secrets or telemetry data.
- Shows a capability-gated update banner and a manual **Check for updates**
  action when a newer release is available.
- Opens only the fixed first-party Windows download route after the user chooses
  **Download update**; it does not download or install updates automatically.

## Compatibility

Existing Kytto settings and client configuration files remain compatible. Update
metadata is stored in Kytto's ordinary settings file and contains only public
release information.
