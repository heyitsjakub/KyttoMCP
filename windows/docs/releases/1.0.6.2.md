# Kytto 1.0.6.2 for Windows

This release packages the current Windows port at the version aligned with the
latest macOS release source. It keeps the security hardening introduced in
1.0.6.1: Kytto's own configuration copies remain private to the account that
made them, and restoring a backup writes only to a file managed by that client.

## Highlights

- Modernized first-run onboarding shows the detected workspace, client icons,
  server/client metrics and the read-only safety boundary before entering the
  matrix.
- Refined matrix navigation now animates in the direction of the selected
  panel, with a more spacious responsive visual system across the shell.
- Backups, parked server definitions and their containing stores use protected
  Windows access lists from the moment they are created.
- Existing Kytto data is repaired at startup when an earlier version left it
  readable by another local account.
- Restore validates the destination against the client's current registry and
  path override before writing anything.
- Configuration writes preserve the source file's existing permissions.

There are no IPC command, event, request or response-shape changes in this
release. The installer and ZIP are unsigned beta artifacts unless the release
build is run with the signing certificate configured.

This file describes the source release. Building, signing, packaging and
publishing Windows artifacts remain separate release steps in
