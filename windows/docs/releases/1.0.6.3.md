# Kytto 1.0.6.3 for Windows

This release follows the macOS 1.0.6.3 source: Settings are reachable from
inside the window, not only from the keyboard, and the panels that could outgrow
the window are confirmed to scroll. It replaces 1.0.6.2, which does not need to
stay on offer.

## Highlights

- The sidebar's footer now carries a Settings row, under the diagnostics count.
  It opens the same native Settings window as `Ctrl+,`, and never takes the
  selected rail, because it goes to a window rather than to a panel.
- New IPC command `settings.open` ([`../ipc.md`](../ipc.md)): the web layer
  states the intent, and what a settings window is — including which keystroke
  this platform spells it with — stays native (§3.2). The reply returns
  immediately rather than waiting for the modal dialog to close.

## Scrolling in MCP Doctor, Activity and Profiles

The macOS release fixes a bug where those three panels clipped anything below
the window's bottom edge. This port does not carry it: `#content` is a column
flex box here, and `.profiles-panel`, `.doctor-panel` and `.activity-panel`
already scroll themselves through `flex: 1 1 auto; min-height: 0; overflow-y:
auto`. The macOS fix reaches the same contract with `min-height: 100%`, so the
two builds now agree; nothing changed in this stylesheet for it, and it was
re-checked in the real window for this release.

## Notes

Request and response shapes are otherwise unchanged. The installer and ZIP are
unsigned beta artifacts unless the release build is run with the signing
certificate configured.
