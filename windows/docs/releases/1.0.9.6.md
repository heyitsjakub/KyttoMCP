## What this release ports

- **The shared web UI** (`1440b77`). Windows now loads `../web`, the same UI as
  macOS. It was built and run on Windows for the first time in this release; see
  *Verified* below.
- **Definition sources, project copies and launch reviews** (`50a1b77`, which
  implemented them on macOS only). The Windows backend now provides the
  `definitions`, `launchReviews` and `launchReviewStorageError` state fields, the
  `project-copy` capability and the commands `servers.projectCopyPreview`,
  `servers.applyProjectCopy` and `launch.acknowledge`
  ([IPC contract](../ipc.md#definition-sources-project-copies-and-launch-reviews)).
- **TOML nesting limit** (`50a1b77`) was already in the Windows parser in that
  commit; its test passes here.

## Windows-specific decisions

- **Locations live beside the copies, not in them.** `ClientDefinition` is a record
  and Unify compares copies with `!=`; a file path inside it would make every two
  clients' copies differ. `Server.Locations` holds the file and exact key instead.
- **Workspace keys are normalized.** Claude Code writes a Windows project key in
  `~/.claude.json` with forward slashes; a folder chosen in Kytto is a full path with
  backslashes. Priority compares them ignoring separators, case and a trailing
  separator, and names the folder as chosen. macOS compares the strings exactly.
- **Restoring a backup records the restored digest** before the next read, so a
  restore is never reported as an outside change. Every other Kytto write already
  recorded its digest.
- **Reading the files again** before a preview, an import or an acknowledgement is
  `ReloadInBackgroundAsync` in the command handler. When that pass changes what the
  page shows, the handler pushes `configs.changed` itself: the watcher's own pass
  would find nothing new and stay silent.
- A Gateway route is recognised by `kytto-mcp-proxy` with or without `.exe`.
- `ProjectCopyException` and `LaunchReviewStaleException` are reported with the
  `appState` code.

## Shared UI fix

`web/css/app.css`: in the inspector's *Definition sources*, a grid item took the
width of its longest unbreakable run, so a deep path (common on Windows) pushed every
copy past the panel's edge. Items may now shrink and long runs wrap. This affects
macOS identically.

## Verified

- `dotnet build`: 0 errors (the known `WFO0003` manifest warning remains).
- `dotnet test`: Core **1294** passed, App **287** passed (12 new), run one after
  the other. `cd ../web && npm test`: **143** passed.
- New App tests (`ProjectDefinitionTests`, the same scenarios as macOS
  `ProjectDefinitionTests.swift`): scope priority with four copies; preview →
  import → removal leaves the source byte-identical and the destination's other
  keys intact; a changed source, a raced destination, an unsupported setting, a
  project input or a Gateway route never writes; launch reviews ignore whitespace
  and Kytto's own writes, merge later changes under a new token, survive relaunch,
  never store a value, and an unreadable review file is reported and left alone;
  restore is not an outside change; a forward-slash project key matches the folder;
  the commands through the router, including `appState` on a spent token.
- `ProjectCopyWebViewTests`: the real window and WebView2 driving the shared UI —
  inspector *Definition sources*, *Import project definition…*, preview (source
  path and variable names shown, no value), import, then Undo back to `absent`.
- `WireFormatTests` pin the new keys.
- Run by hand on an isolated profile (`KYTTO_TEST_HOME`): matrix badges
  *multiple scopes* and *launch changed*, the inspector's sources and priority, the
  import preview, a launch change made to a file while the app ran (picked up by
  the watcher, saved masked, still there after relaunch, cleared by *Mark as
  reviewed*), and the MCP Doctor, Profiles and Secrets screens.

- Driven with [Cua Driver](https://github.com/trycua/cua) 0.54.0 through UI
  Automation on the Debug build of `69e7bfa` and an isolated profile — real clicks
  rather than injected script: open *Demo*, *Import project definition…*, choose
  Cursor, *Preview copy*, *Import definition* (one entry added, other keys and
  formatting kept, backup taken), *Undo* (the entry removed, the rest of the
  file as it was), an outside edit raising *launch changed*, and *Mark as reviewed*
  clearing it. An HTML `<select>` ignores UIA value writes and background keys;
  the destination was chosen with foreground arrow keys.
- The packaged app reports `1.0.9.6+69e7bfa…` and contains the shared `web/`
  (`definitionSources.js`, `compat.js`, the CSS fix).
