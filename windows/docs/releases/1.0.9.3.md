# Kytto 1.0.9.3 for Windows

**Source release 1.0.9.3 · not yet published.** Unsigned build, same as 1.0.9.2.

User-facing changes are in the repository root `CHANGELOG.md` under `## [Unreleased]`.
This file records what was built, what was checked, and what was not.

## What changed

- **Restart now (#14).** The pending-restart notice offers *Restart now* per client, and
  *Restart all* when several apply. The shell quits the client's desktop app, opens it again,
  and reports each client as restarted, not running, or failed. Failures keep their notice.
  Claude Desktop, Cursor, VS Code, Antigravity and Devin Desktop restart this way. Claude
  Code, Codex and OpenCode stay on *I restarted*: they are terminal-first.
- **Maximised window above the taskbar (#15).** The frameless window answers
  `WM_GETMINMAXINFO` with its monitor's work area, and leaves one pixel for an auto-hide
  taskbar. The 40 px title strip compensation this needed is gone.
- **Caption buttons (audit W-01, W-02, W-13 in part).** They live in an owned, never-active
  overlay window instead of a topmost popup, so they stay visible when another app is
  active and no longer float off the window at a screen edge or a monitor seam. Screen
  readers get names.
- **Native audit (W-03 to W-12, W-15, W-16).** See the changelog. Single-instance guard
  (W-05), an app-level exception handler (W-06), per-monitor DPI manifest (W-09).
- **Web audit (W1 to W15, excluding W16).** Focus restoration, the Skills/Library warning
  crash, matrix layout at 1280 px, onboarding clipping, the drag strip on first-run and
  error screens, busy toggles keeping focus, the sticky restart bar height, secret and
  diagnostic wrapping, the toolbar height, sheet error styling, Check visible during a
  single check, and wording.

## Verified

- `dotnet build` of `KyttoMCP.slnx`: 0 errors, 0 warnings.
- Kytto.Core.Tests: 1128 of 1128 pass.
- Kytto.App.Tests: all pass (WireFormatTests pins the two new `ClientDTO` keys,
  `canRestart` and `restartCaveat`).
- Web (`npm test`): 135 of 135 pass.
- Restart: the process matcher, reopen path, and the tray-resident case were run against a
  copy of a system binary in a temporary directory, so no real client was ever touched.
- #15: a Debug build run with `KYTTO_TEST_HOME` and `KYTTO_TEST_DATA_ROOT` pointing at
  temporary directories, maximised with `SW_MAXIMIZE`, has a window rectangle exactly equal
  to its monitor's work area (1536×816 on a 1536×864 monitor with a 48 px bottom taskbar).
- Caption overlay: the overlay is a visible window owned by the main window, 138×32 px, with
  its right and top edges aligned to the main window (checked by enumerating the process's
  windows).

## Not verified

- Restart against the real Claude Desktop, Cursor or VS Code. The process logic is tested
  against a copy only. Check it on a machine with those installed before publishing.
- The overlay while another app is active, and the caption placement after a DPI change on
  a second monitor. Both need a person at the screen.
- The taskbar on the left, top, and right edges, and with auto-hide on. Only the bottom
  taskbar, auto-hide off, was measured.
- W-14 (High Contrast glyphs), W-01/W-02 snap-layout flyout (`WM_NCHITTEST`), W-16 (very
  wide windows), W3's bounded table scroll, and the macOS-web items in the audit that were
  not checked against Windows code.
- Installer build and SHA-256. Not built for this draft.
