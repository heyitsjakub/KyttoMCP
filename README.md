# KyttoMCP

> Your MCP setup, finally in one place.

KyttoMCP is a local desktop control panel for managing Model Context Protocol (MCP) servers across the AI clients you already use.

It reads the configuration files on your computer and gives you one clear view of what is configured and enabled where — without manually hunting through JSON and TOML files.

## Features

- Manage MCP servers across Claude Desktop, Claude Code, Cursor, VS Code, and Codex
- See the client/server matrix in one place
- Enable or disable servers while respecting each client’s configuration rules
- Inspect server health, tools, protocol details, and estimated context cost
- Create local profiles for different workflows
- Keep sensitive configuration values masked and stored locally
- Create timestamped backups before changes and restore previous configurations
- Optionally use Gateway mode to inspect local sessions and tool-call metadata

## Local by design

KyttoMCP works with the configuration files already on your computer.

- No account or sign-up
- No cloud sync
- MCP configurations and credentials stay local
- Backups and configuration changes are handled locally
- Optional anonymous diagnostics are off by default
